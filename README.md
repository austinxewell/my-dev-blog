# AuEwellify — Personal Development Blog

This is my personal developer blog built with **Jekyll** and hosted on **GitHub Pages**. It’s where I share insights, tutorials, and thoughts on development, software engineering, and the projects I’m working on.

## 🧠 About the Blog

The goal of this site is simple — to document my journey as a developer, share what I learn, and connect with others in the dev community.  
Expect posts about JavaScript, Vue, Nuxt, React, CSS, design systems, and general problem-solving in modern web development.

**Live Site:** [AuEwellify Development Blog](https://austinxewell.github.io/my-dev-blog/)

## ⚙️ Tech Stack

- **Jekyll** — static site generator
- **Markdown** — for post content
- **GitHub Pages** — hosting and deployment
- **Liquid** — templating engine
- **Sass / CSS** — styling and layout

## 🚀 Running Locally

Clone the repo and serve it locally with Jekyll:

```bash
# Clone the repo
git clone https://github.com/austinxewell/my-dev-blog.git

# Navigate into the directory
cd my-dev-blog

# Install dependencies
bundle install

# Serve locally
 bundle exec jekyll serve --config _config.yml,_config.dev.yml

# Visit in your browser
http://localhost:4000 or {ip}:4000
```
